# 发布审计

本页记录公开版本的可复核门禁，不记录秘密原文。最终在线结果以 GitHub Actions 和
仓库 Security 页面为准。

## 1.0.0 范围

- 源码、测试、示例、文档、图片和图片元数据；
- 当前工作树与所有可达 Git 历史；
- Windows 本地运行入口与 Linux systemd 部署路径；
- 后台登录、公开取件页、健康接口、四套主题、SVG/ICO 图标；
- Python 3.10–3.13 单元测试、Ruff、Bandit、pip-audit、detect-secrets、Gitleaks、
  GitHub Actions CI 与 CodeQL。

## 人工复核边界

- Bandit 对固定 SQL 片段的 B608 报告需逐项确认：动态部分只能来自代码内白名单，
  所有用户值继续使用 SQLite 参数绑定。
- 外部 URL 读取只接受 `https`，且主机必须属于 `ipwho.is` 或 `ipapi.co`；该功能默认关闭。
- 示例中的密码语义仅用于格式说明或隔离测试，不是可用凭据。

## 2026-08-08 结果

- Python 3.12 编译通过，32 项单元测试通过；Ruff 与完整 Bandit 扫描均为零未解决项。
- 运行时没有第三方依赖；pip-audit 报告无已知漏洞。开发审计工具固定了明确版本。
- detect-secrets 与 Gitleaks 工作树扫描均无命中；独立公开副本的首个 Git 提交经
  Gitleaks 完整历史扫描，同样无命中。
- 邮箱只使用 `example.com`、`example.test` 或明确标记为测试的服务商路由夹具；IP
  只使用本机地址和 RFC 5737 文档地址；未发现用户目录、姓名、账号或部署身份。
- 桌面端在真实浏览器中检查了天际蓝和深灰夜色主题、主题菜单、登录表单及图标。
  预览来自这次合成数据运行，不含真实邮箱或 token；两张 PNG 元数据为空，社交封面
  为 1280×640、69 KB。
- B608 的两处保留项只拼接由列表长度生成的 `?` 占位符，所有值均通过 SQLite 参数
  绑定；B310 位置在调用前同时校验 HTTPS scheme 与固定主机白名单，且功能默认关闭。

本次本地发布门禁没有未解决的秘密、个人信息、高风险静态告警或已知依赖漏洞。远端
GitHub Actions、CodeQL 与仓库安全设置必须在推送后再单独在线核验。
